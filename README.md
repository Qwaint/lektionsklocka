Lektionsklocka v1
 
Visar automatiskt pågående lektion, aktuell klocka, en visuell nedräkningsring och minuter kvar.

 
Schema: Tryck Redigera schema. En lektion per rad: mån,10:40,11:30,EK25

 Dagar: mån, tis, ons, tor, fre, lör, sön.

 Schemat sparas lokalt i webbläsaren.

 Användning
index.html är hela appen. Lägg den på valfri statisk webbserver för att använda den smidigt på iPad. Därefter kan sidan läggas på hemskärmen via Safari.

 Appen räknar återstående tid från iPadens klocka och lektionens sluttid, så ingen separat timer behöver startas.
